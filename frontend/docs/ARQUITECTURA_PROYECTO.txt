3. ARQUITECTURA DE LA APLICACIÓN
--------------------------------

La aplicación está organizada siguiendo una separación por responsabilidades:

- Entrada de la aplicación:
  `src/main.jsx` crea la raíz de React, habilita StrictMode, importa los iconos
  de Bootstrap y envuelve la aplicación con `AuthProvider`.

- Componente raíz:
  `src/App.jsx` compone la página pública `Home` y el `AuthModal`, además de
  cargar los estilos globales.

- Páginas:
  La carpeta `src/pages` contiene vistas completas. Actualmente existe la
  página pública `Home`; las páginas administrativas están previstas, pero la
  carpeta aún está vacía.

- Componentes:
  La carpeta `src/components` contiene piezas reutilizables. Se divide por
  dominio (`auth`, `citizen`, `user`, `admin`) y por uso transversal (`common`).

- Estado global:
  `src/context/AuthProvider.jsx` centraliza el contexto relacionado con la
  autenticación y permite compartirlo entre componentes.

- Presentación:
  Los archivos `.css` ubicados junto a cada componente mantienen los estilos
  cercanos al componente correspondiente. `src/styles/global.css` contiene las
  reglas globales.

- Recursos:
  Los recursos importados desde JavaScript/JSX se encuentran en `src/assets`.
  Los recursos estáticos que deben publicarse directamente se encuentran en
  `public`.

- Navegación:
  `src/routes` está preparada para concentrar las rutas de la aplicación,
  aunque actualmente no contiene archivos. El proyecto incluye
  `react-router-dom` como dependencia.

- Backend:
  La carpeta `backend` existe como límite arquitectónico para la futura API,
  persistencia y lógica del servidor, pero todavía no tiene implementación.


4. TECNOLOGÍAS Y DEPENDENCIAS PRINCIPALES
------------------------------------------

Runtime y framework:
- React 19.
- React DOM 19.
- Vite 8 como herramienta de desarrollo y build.
- JavaScript con módulos ES (`type: module`).

Navegación e interfaz:
- React Router DOM 7.
- Bootstrap Icons 1.13.
- CSS plano organizado por componente.

Calidad y desarrollo:
- ESLint 10.
- Plugins de ESLint para React Hooks y React Refresh.
- Plugin de React para Vite.


5. SCRIPTS DISPONIBLES
----------------------

Los scripts definidos en `frontend/package.json` son:

- `npm run dev`       Inicia el servidor de desarrollo de Vite.
- `npm run build`     Genera la compilación de producción.
- `npm run lint`      Ejecuta ESLint sobre el frontend.
- `npm run preview`   Sirve localmente la compilación generada.


6. FLUJO DE ARRANQUE ACTUAL
----------------------------

1. El navegador carga `frontend/index.html`.
2. `src/main.jsx` obtiene el elemento raíz y monta React.
3. React renderiza `AuthProvider` como proveedor global.
4. `AuthProvider` contiene a `App`.
5. `App` muestra `Home` y `AuthModal`.
6. Los componentes utilizan sus archivos CSS y los recursos de `src/assets`.
